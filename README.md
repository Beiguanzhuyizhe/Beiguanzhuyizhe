## About

I'm a Computer Science undergraduate in the IEEE Honor Class at **Shanghai Jiao Tong University** (2024–2028) and a member of **MVIG-RHOS**. My research interests include multimodal game understanding, cross-domain visual representations, and vision–action model adaptation. I also build simulation and evaluation tools, design games, and enjoy turning ideas into playable experiences.

## Research

My current interests sit at the intersection of **game AI, visual learning, and interactive simulation**:

- **Multimodal game understanding** — Learning from gameplay video and action trajectories to understand what happens on screen and how it relates to player actions.
- **Cross-domain vision–action learning** — Evaluating pretrained visual representations and adapting vision–action models to game environments with lightweight training.
- **Attention for agent decision-making** — Exploring how gaze and temporal attention can inform agents' perception and decisions.

| Research project | My work |
| :--- | :--- |
| **Game Attention** | Built an attention-data collection pipeline and explored webcam gaze estimation, saliency prediction, BubbleView, and model-assisted annotation as groundwork for attention-aware game agents. |
| **Visual Simulation & Closed-Loop Evaluation** | Built multimodal data pipelines and automated evaluation tools with Unreal Engine and AirSim, connecting visual detection, control decisions, execution, and feedback. This work is part of my research at SJTU's John Hopcroft Center for Computer Science. |
